Noto Sans SC (Regular / Bold)
=============================

These font files are bundled so the JavaFX WebView can render Chinese text
correctly on macOS 15 and later, where JavaFX may otherwise fall back to a
Japanese font (OpenJDK issue JDK-8374013).

Source:
  Maven Central: com.helger.font:ph-fonts-noto-sans-sc:5.0.4
  Upstream:     https://github.com/notofonts/noto-cjk
